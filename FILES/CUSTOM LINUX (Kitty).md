
## ? Sistema (Ventanas y Entornos)  
  
| Atajo | Acción |  
|-------|--------|  
| **Win + Enter** | Abrir terminal |  
| **Win + Q** | Cerrar ventana / aplicación |  
| **Win + D** | Abrir Rofi |  
| **Win + Alt + ⮕ (o dirección)** | Redimensionar ventanas |  
| **Win + S** | Desacoplar ventana |  
| **Win + Click Izq.** | Mover ventana desacoplada |  
| **Win + Click Der.** | Redimensionar ventana desacoplada |  
| **Win + Alt + ⮕ (o dirección)** | Redimensionar ventana desacoplada |  
| **Win + T** | Acoplar ventana |  
| **Win + F** | Pantalla completa |  
| **Win + [1...9]** | Seleccionar otro entorno de trabajo |  
| **Win + Shift + [1...9]** | Mover lo que esta en entorno actual al seleccionado |  
  
  
---  
  
## ? Preselectores  
  
| Atajo | Acción |  
|-------|--------|  
| **Ctrl + Win + Alt + ⬆ / ⬇ / ⬅ / ⮕** | Crear y posicionar preselector |  
| **Ctrl + Win + [1...9]** | Cambiar tamaño de preselector (a un % de la pantalla completa) |  
| **Win + Alt + ⮕ (o dirección)** | Redimensionar ventana |  
| **Win + Shift + [número]** | Mover ventana a otro escritorio |  
| **Win + Shift + `** | Mover ventana a otro entorno de trabajo |  
  
  
---  
  
## ? Kitty (Gestión de terminales)  
  
| Atajo | Acción |  
|-------|--------|  
| **Ctrl + Shift + Enter** | Crear split (nueva terminal dentro de Kitty) |  
| **Ctrl + Alt ⬆ / ⬇ / ⬅ / ⮕** | Seleccionar split |  
| **Ctrl + Shift + R** | Redimensionar split actual |  
| **Ctrl + Shift + Z** | Hacer o Quitar zoom en split activo (traer a primer plano en pantalla completa) |  
| **Ctrl + Shift + L** | Reacomodar los splits abiertos de diferentes formas en la pantalla completa (muy bueno) |  
| **Ctrl + Shift + W** | Cerrar split |  
| **Ctrl + Shift + T** | Crear nuevo entorno de trabajo (dentro de Kitty) |  
| **Ctrl + Shift + Alt + T** | Renombrar entorno de trabajo |  
| **Ctrl + Shift + [⬅ / ⮕]** | Movernos entre entornos de trabajo |  
| **Ctrl + Shift + Q** | Cerrar entorno de trabajo |  
| **Ctrl + T** | Buscar archivos/rutas |  
| **Ctrl + R** | Buscar en historial de comandos |  
  
  
---  
  
## ? Seguridad  
  
| Atajo | Acción |  
|-------|--------|  
| **Win + Shift + X** | Bloquear pantalla |

## ? Archivo sxhkd (atajos) y bspwm (rutas y aplicaciones)  
  
| Atajo | Acción |  
|-------|--------|  
| **Win + Esc** | Aplicar cambios hechos en el archivo |  
| **Win + Shift + R** | Recargar el bspwm |  
| **Win + Shift + Q** | Cerrar bspwm (regresa a la página de inicio de sesión de Parrot) |

## ? Funciones (Polybar y utilidades)  
  
| Comando | Acción |  
|---------|--------|  
| **settarget [IP]** | Indicar en polybar la IP seleccionada |  
| **cleartarget** | Limpiar IP indicada en polybar |  
| **creartarget** | Crear un nuevo target |
